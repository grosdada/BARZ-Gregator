# Quaternius Studio assets

Ragdoll Studio bundles a compact flat-color conversion of the Quaternius
Universal Base Characters `Superhero_Male_FullBody` model and the Standard
in-place Universal Animation Library.

- `superhero-male-flat.glb`: 69-node rigged mannequin, textures omitted.
- `UAL1_Standard.glb`: 45 embedded animation clips.
- Both source packs are dedicated to the public domain under CC0 1.0.
- The application links to the official download pages so users can retrieve
  the complete current packs directly from Quaternius.

Official sources:

- https://quaternius.itch.io/universal-base-characters
- https://quaternius.itch.io/universal-animation-library

Technical mirrors used for the bundled GLBs:

- https://github.com/programasweights/avatar
- https://github.com/richardanaya/metaverse-avatar
