AI Video and Image Prompting Reference

Compiled 2026-10-03. Scope: Seedance 2.0 and 2.5, Wan 3.0, FLUX 3 (video and image), MiniMax H3, Kling 3.0 and Kling 3.0 Omni ("O3"), Nano Banana family, GPT Image family, Z-Image, FLUX image family, Seedream, Midjourney, plus directing, staging, cinematography and control techniques (3D blockout, path maps, keyframes, control signals).

0. How to use this document (instructions for any LLM)

This file is a knowledge base for a language model whose job is to write generation prompts. It is self-contained: all content is plain text in semantic HTML, no script is required to read it. Section ids are stable and can be cited (for example #seedance-25, #blockout).

0.1 Procedure to follow for every prompt request

  1. Identify the engine and the host platform. Reference syntax depends on the platform, not only on the model (see 3.7). If unknown, ask.
  2. Identify the mode from what the user has: text only, one image, two frames, several references, a clip to edit, a clip to extend, a 3D blockout.
  3. Check hard limits in the engine card (duration, references, prompt length). Duration, ratio and resolution are parameters, not prose.
  4. Design the shot first with sections 6, 7, 8: who is where, what happens, what the camera does, what the light does, what is heard.
  5. Compile into the engine dialect using the engine card: block order, reference tokens, multi-shot marker, dialogue and audio syntax, how exclusions are expressed.
  6. Run the checklist in section 12, then deliver the prompt as one paste-ready block plus a short settings line.

1. Universal principles (valid on every current engine)

  1. Describe what the camera sees and the microphone hears. Every abstract word ("cinematic", "emotional", "dynamic", "premium") must be replaced by a visible or audible change. If you cannot say what the viewer would see, the model cannot render it. [P]
  2. One shot, one action, one camera move. Two actions means two shots. Stacked moves cause jitter or unwanted cuts. [O: OpenAI, Runway, Alibaba] [P]
  3. Image-to-video prompts describe motion, not the picture. The image already locks the look. Re-describing it reduces motion. Restate only light and lens so the join does not drift. [O: Runway, Alibaba, OpenAI]
  4. States, not transitions. Models fail processes and nail states. Write "mid-throw, arm extended", not "reaches into the bag, pulls out, winds up". Chain states beat by beat. [P]
  5. Stage long clips in beats. Each beat has a starting state, one event, and an observable end state. Without beats, the first three seconds are right and the rest drifts. [P]
  6. Timestamps are time budgets, not edit points. Adherence is around one second on current engines. Never conform to a music grid from timestamps alone. [3P] [P]
  7. Every reference gets a job and an exclusion. Say what it defines and what to ignore (its background, its lighting, extra people). An unassigned reference bleeds everything. [3P] [P]
  8. Do not describe what a reference already carries. If a video reference supplies the camera, describing a camera in text creates a conflict the model splits down the middle. [3P] [P]
  9. Positive phrasing first. Most engines have no negative-prompt field. Naming an unwanted thing can inject it. Write the desired state ("empty deserted street"), then at most a short local lock. Exceptions with a real negative field: Kling 3.0 API, Z-Image Base, Wan 2.7, Midjourney --no. [O]
  10. Audio is always generated unless told otherwise. Name every layer you care about. Silence and "no music" must be requested explicitly. [O: BFL] [P]
  11. Dialogue: short, quoted, attributed. About 2.5 words per second. Name the speaker by a visible trait. Ask for no subtitles. [P] [3P]
  12. Put first what matters most. Early words weigh more on most models. Subject and style anchors go before motion. [O: BFL] [P]
  13. Length is a ceiling, not a target. A long prompt is work the writer refused to hand to a reference. Dense where control matters (identity, blocking, optics, light, timing), sparse elsewhere. [P]
  14. Parameters are not prose. Duration, aspect ratio, resolution, fps and seed are set in the UI or API. Writing "30 seconds" or "16:9, 4K" in the text does nothing or dilutes attention. [O: OpenAI] [3P]
  15. Iterate surgically. Change one line, keep the rest verbatim. Test on a 3 to 4 second excerpt or a draft pass before a full render. [P]
  16. Never name the fabrication technique. "Latex", "puppet", "prosthetic", "CGI", "miniature" are rendered literally and produce plastic. Describe the visible result. [P]

2. The canonical shot spec (engine-independent)

Write the shot once in this neutral form, then compile it into the engine dialect. The blocks are the invariant, the syntax is not. Order matters: spatial rules come before camera style, optics before general aesthetics. [P]

#BlockContent
1Scene contextOne or two sentences: what happens in this shot only. No scene numbers, no previous-shot wording.
2Active referencesOnly the tags visible or audible in this shot, each with role and exclusion.
3Location mapCamera position and facing, foreground, midground, background, landmarks, light direction.
4First frame and spatial blockingWho is where in frame one: screen position, distance to landmark, body facing, gaze target.
5Format modeSingle continuous take, or controlled multi-shot with every cut named.
6OpticsLens character as field of view or focal length, camera distance, visible optical outcome.
7CameraHeight, side, angle, one movement, focus behaviour.
8Action timingBeats with time ranges, one event per beat.
9PhysicsWeight, contact, inertia, cloth and hair delay, liquids, particles.
10LightingSource, direction, camera side relative to light, exposure priority.
11AudioDialogue, ambience, effects, music or its absence, mix order.
12Character actingObjective, tactic, beat changes, business, eye life (7.5).
13StyleThe style prefix, pasted verbatim in every shot of the same world.
14QualityShort suffix only if useful: stable picture, sharp clarity, natural colours.
15Constraints and exclusionsPositive locks, plus an exclusions list whose fate the engine decides (negative field, inline lock, or end-of-prompt list).

3.1 Seedance 2.0 (ByteDance; Jimeng, Dreamina, BytePlus ModelArk, Higgsfield)

Modes and specs

  • Text-to-video, image-to-video (first frame, first plus last frame), multimodal reference-to-video, video editing, video extension. Variants: standard, fast, mini. [O/3P]
  • 4 to 15 seconds, 24 fps. Ratios: auto, 21:9, 16:9, 4:3, 1:1, 3:4, 9:16. [O/3P]
  • References: up to 9 images, 3 videos, 3 audio clips; 12 files; combined video 2 to 15 s; combined audio 15 s. [O/3P]. Audio count differs on one BytePlus page [U].
  • Identifiable real human faces are restricted. [3P]

Prompt structure

  • Order: Subject, Motion, Environment, Look, Camera, Audio. Only subject and motion are essential. [3P]
  • The first 20 to 30 words weigh most: pin the subject there (2 or 3 hard visual traits, wardrobe). If the subject is not established in the opening sentence, a new character appears at each cut. [P]
  • Length: 60 to 150 words. Beyond about 300 words, or about 1800 characters, the tail is ignored. [3P] [P]
  • Use rhythm words (slow, smooth, steady, rapid). Avoid f-stops, ISO, fps. Prefer field of view in degrees plus camera distance over millimetres (see 8.1). [P]

References

  • Token: @Image1, @Video1, @Audio1 on fal [3P]; @图片1, @视频1 in the official BytePlus doc [O]; custom @TAG handles on Higgsfield [P]. Numbering is per type, in upload order.
  • "Use as first frame" pins; "reference" borrows. Always assign the job. [3P]
  • Character line formula [P]: @TAG: age + role or body type + current state + critical visible anchors + action-critical prop. 100% matches the reference. Do not overwrite the reference with long prose.

Multi-shot, dialogue, exclusions

  • Multi-shot marker: Cut to. between shots in one flowing paragraph (about 3 shots reliable; 3 to 7 used in production) [3P] [P]; or time ranges 0-4s:; or HARD CUT with a named time [P].
  • Each shot states four things: shot size, lens, angle, one movement verb. Vary all four between consecutive shots. Each shot 2 to 5 seconds. [P]
  • One take: write "one continuous shot, no cuts". [3P]
  • Dialogue: the line in double quotes, short; describe delivery in prose; subtitles appear unless refused. Unspecified audio defaults to music: write "no music". [3P]
  • No negative-prompt field. Use positive constraints ("stable picture, sharp clarity") and short local locks ("no flat front light"). [3P] [P]

Failure modes

  • Vendor-admitted: detail stability, occasional audio distortion, multi-subject consistency, text rendering, complex edits. [O]
  • Instruction overflow, unassigned references bleeding, stacked camera moves, mixed-language prompts garbling on-screen text, too many locations per clip, long monologues losing lip-sync. [3P]

3.2 Seedance 2.5 (ByteDance; released 2026-07-31)

Not Seedance 2.0 with a longer timer: the grammar changed. Prompts tuned for 2.0 can glitch on 2.5. [3P] [P]

Modes and specs

  • Text-to-video, image-to-video (first, first plus last), reference-to-video, ordered keyframes, clay-render (3D blockout) referencing, motion referencing, timestamp-level editing, region editing, green-screen editing, camera-perspective editing, forward and backward extension. [O]
  • 4 to 30 seconds per pass [O]. Extension ceiling disputed: "extend twice", 90 s reported in hands-on tests, 180 s beta on Dreamina [O/U].
  • References: up to 30 images, 10 videos, 10 audio, 50 total [O]. Video pool and audio pool about 30 s each [3P]. One BytePlus page lists only 3 videos [U].
  • Stable range in practice: at most 8 image-defined subjects, at most 5 when a video reference is loaded. [3P] [P]
  • Resolution is channel-dependent (see comparison table). API model id on BytePlus: dreamina-seedance-2-5-260628 [O]. Other ids circulate [U].
  • Native audio with lip-sync in 11 languages: Chinese, English, Spanish, Indonesian, Malay, Thai, Arabic, Portuguese, Vietnamese, Japanese, Korean [O]. French and German are not confirmed [U].
  • Locked parameters [P]: region edit locks ratio and duration to the input (drift up to about 0.3 s); first/last frame locks ratio to the first image; extension locks ratio to the source.

Prompt formula

Subject + Action or event + Scene and environment + Visual style + Camera work + Sound. Only subject and action are mandatory. Write prose, not labelled fields. Place style anchors (maximum two) before motion. [3P reporting the official guide] [P]

Beats and timing [P] [3P]

0-6 s    Opener. Wide or establishing. Orient the viewer, set the light.
6-14 s   Development. Move in. One clear action.
14-24 s  Escalation. Movement, insert or reversal. The turn happens here.
24-30 s  Resolution. Close-up callback. Land on a held image.
  • Three timing grammars, mixable: range (0-5 s: ...), exact point (At 5 s the camera whip-pans left), relative (Two seconds after the door closes...).
  • Ranges must be consecutive with no gaps. One main change per range. Too many exact timestamps make actions vanish.
  • In-pass cut: name it and say how it connects: Cut on the hand movement to a medium shot, same room, same light.

Reference binding

  • Token: @Image 1, @Video 1, @Audio 1, @Clay Render 1 with a space on Dreamina [O]; @Image1 without space on fal [3P].
  • One line per file: what it defines, what to ignore. One name per file. Never "images 1 through 4 define four characters". [P]
  • Several views of one object must be declared as one object: "@Image 1 and @Image 2 are the same shoe, front and side. The output must show only one shoe." [P]
  • Trim priority: characters, hero props, set, palette. [P]
@Image 1 defines the man's face, hairstyle and navy jacket. Do not use its background or the second person at the edge of frame.
@Image 2 defines the diner set: booth layout, wall tiles, window position.
@Video 1 defines the camera move and pacing only. Do not use its subject or its colour grade.
@Audio 1 defines the man's voice timbre. Do not use its room noise.

Specialised modes [P]

  • First and last frame: describe the journey, not the endpoints. Both stills must share the aspect ratio.
  • Ordered keyframes: Use @Image 1 through @Image 5 as keyframes in this order. One key state per image; say how to travel (evenly, with holds, with cuts).
  • Region edit, four mandatory parts: edit goal, source role, target role, preservation list. Missing one produces a full regeneration.
  • Extension: lock the boundary frame as a state, then the new action, then continuity rules (grade, ambience, wardrobe, position).
  • Blockout: see 5.1.

Exclusions

No negative field [3P]. Prohibitions in plain language work best as preservation statements: "Do not change the room layout. No on-screen subtitles. No background music." Use count locks ("exactly one...", "no duplicate..."). For 2D styles, suppress the render signature: 3D render, ambient occlusion, depth map, CGI texture, photorealistic skin, glossy plastic, volumetric light, ray tracing, soft gradient shading. [P]

Failure modes

  • Vendor-admitted: physical plausibility of complex motion, stability of multi-subject interaction. [O]
  • Fast action morphs; voice or accent drift if unspecified; close-up faces soften at 720p; no partial re-roll. [3P]
  • video_edit cannot move geometry (widening a room returns the same result). Exact on-screen text is unreliable: composite in post. [P]

3.3 Wan 3.0 (Alibaba Tongyi; wan3.0-video, wan3.0-video-prime)

Modes and specs [O]

  • One unified model: text-to-video; first frame; first plus last frame; multimodal reference; video editing (style, dialogue, elements); extension forward, backward or both; document or web link to video.
  • Mutual exclusion: first/last frame cannot be combined with references, files or links in the same request.
  • 2 to 30 seconds, or -1 for smart duration. With a source video, input plus output stays within 30 s.
  • 480P, 720P, 1080P (default). 30 fps fixed. Ratios: adaptive, 21:9, 16:9, 4:3, 1:1, 3:4, 9:16.
  • References: up to 10 images, 5 videos (15 s total), 5 audio (15 s total), 1 file, 1 link, 20 materials. Documents up to 100 MB and 50 pages.
  • Prompt up to 20,000 characters. prompt_extend is on by default: turn it off for long structured prompts, it rewrites labels and timestamps [3P].
  • No open weights, no local inference [P]. Official special workflows: storyboard grid, clay render, red-line camera path drawn on an image, action or camera or VFX transfer from video, audio-driven beat, timbre and lip-sync.

Official prompt formula [O]

[Overall description] + [reference citations with roles]
Shot 1 [0-3s]: subject + scene + motion + aesthetics + dialogue + sound or BGM + style and mood
Shot 2 [3-7s]: ...
[Negative list at the very end: No subtitles. No watermark. No slow motion.]
  • Shot markers accepted: Shot 1 [0-3s], Segment 1 (00:00-00:03), [00:00-00:03]. Segments contiguous, 2 to 5 s each. Transitions: "hard cut", "dissolve".
  • Single take: write "Generate single shot" or "One continuous shot" on the first line. For long one-takes, describe the camera as one path with stations: "opens on A, holds 2 seconds, then moves toward B as..." [P]
  • Subject lock in the first 25 words; restate subject traits after every cut ("the same man in the ochre jacket"). [O] [P]

References [O]

  • Token: plain Image 1, Video 2, Audio 1, no @. Images, videos and audio are numbered separately in upload order. OpenArt uses @Image1 on its own UI [3P].
  • Cite by role: "the face and build of Image 1", "the set dressing and palette of Image 2". The same material may be cited several times for different roles.
  • Clay render: state that nothing changes except material and colour; list locked items (camera path, positions, actions, timings).
  • When a reference audio drives lip-sync, do not also write the line as text. [P]

Audio and dialogue [O]

  • Dialogue: character + speaking verb + colon + quoted text: The woman whispers: "...". Multi-speaker: Image 1 says: "..."; Image 2 replies: "...". Voiceover: Voiceover: "...".
  • Voice cloning: "voice timbre references Audio N". Add "Lip sync". Write "No dialogue" when there is none.
  • Music: say nothing (model decides), describe it, or "No BGM, generate only ambient and action sounds". Effects as standalone sentences, optionally timed.
  • Budget about 2.5 seconds of speech per 5 second clip. [3P]

Editing and extension [O]

Edit the video: replace [X] in Video 1 with [Y], keep the rest unchanged.
Edit the video: at 4-6s, change [X]. Keep everything else unchanged.
Extend Video 1 forward: [restate character and scene details], [new action].

Exclusions

No negative_prompt parameter on 3.0. The official guide places a negative list at the end of the prompt, not repeating positive content [O]. Production practice also phrases critical exclusions positively ("the laptop lid is bare brushed aluminium, unmarked") [P]. Wan 2.7 does have negative_prompt (500 characters) [O].

Failure modes

  • Vendor-admitted: audio texture, exact on-screen text, word-exact lip-sync, very long action sequences, rapid scene changes. [O]
  • Short lazy prompts are auto-cut into several stock-like shots. Naming light sources, shot size and angle stops the auto-editing. [3P]
  • Avoid "tripod" (write "static", "locked off") and stacked trailing adjectives ("cinematic, 8k, masterpiece"). [P]

3.4 FLUX 3 Video (Black Forest Labs; endpoint /v1/flux-3-video)

Modes and specs [O]

  • Text-to-video; image-to-video through keyframes (1 image is the start frame, 2 are start and end, up to 10 timestamped keyframes); video continuation; draft then enhance. Editing is a separate tool (FLUX Video Edit: source up to 15 s, no masks, no extension).
  • Reference-to-video ("Omni Reference") is announced, not live in the main API docs; one cookbook mentions reference_images. Treat as unverified. No reference citation syntax is documented. [U]
  • No motion control or 3D blockout input documented. [O]
  • 5 to 20 seconds (continuation 5 to 15 s), 24 fps, so frame index = seconds x 24. Ratios: auto, 21:9, 2:1, 16:9, 4:3, 1:1, 3:4, 9:16, 9:21.
  • Keyframes and continuation cannot be combined in one request. Keyframe positions unique, none beyond the duration. [P]
  • The model rewrites and expands the prompt before generating: what is stated is respected, what is left open is invented. [3P] [P]
  • "Grounding" toggle on fal, on by default; off gives more freedom for surreal shots. [3P]

Prompt shapes [O] [P]

  1. Short phrase for look development.
  2. Natural-language one-liner (default): camera, subject, action, environment, supporting motion, look and sound.
  3. Labelled lines (camera / subject and action / depth of field / lighting / motion / audio / style), best for iterating one line at a time.
  4. Timestep beats: 0.0-1.5s: ... then HARD CUT.

Five elements to cover: subject and action, camera direction, scene and atmosphere, motion qualities, continuity constraints. Plain prose, not keyword lists. Start short, then lengthen. About 5 to 7 seconds per beat. [O]

Multi-shot [O]

SHOT ONE: [framing and action]. HARD CUT.
SHOT TWO: [new framing, angle or location]. HARD CUT.
SHOT THREE: [closing beat].
  • Capitals and full stop matter: HARD CUT. is a directive. Two or three shots per generation.
  • A cut registers only if adjacent shots differ strongly in scale, angle, location or light.
  • Name the music bed once for the whole sequence; name ambience per shot. [P]
  • Longer films: one generation per shot, an identical "world bible" paragraph pasted verbatim, the same musical motif named each time. [O]

Audio and dialogue [O]

  • Four layers: speech, ambience (named sources), effects (tied to visible actions), music (style, pace, mix position). The layer named first sits at the front of the mix. [P]
  • Speech: visible speaker + delivery + exact words in double quotes. Voiceover must be labelled "off-screen voiceover" or "narration".
  • Voice direction: person (age, accent), register, recording perspective, delivery, guardrails ("no announcer delivery").
  • Write the prompt body in English; quote dialogue in the language it is spoken in. [P]
  • Do not ask for "silence": name room tone, or write "no music".
  • Always add no on-screen text, no subtitles when there is dialogue.

Failure modes and fixes [O/3P]

  • Dialogue rendered as captions: add the no-subtitles line.
  • Repeated dialogue: "speaks exactly once, the complete sentence".
  • Last word cut off: shorten the line or lengthen the clip; allow 1 to 2 seconds before speech starts.
  • Default camera is a slow drift: for no movement write "camera locked at eye level".
  • Over-stuffed prompts reduce motion coherence. Complex multi-person coordinated action is hard.

3.5 MiniMax H3 (API ids MiniMax-H3, MiniMax-H3-Max)

Official name is MiniMax H3. "Hailuo 3.0" or "Hailuo 03" is third-party or consumer labelling. Open weights announced 2026-08-03. [O/3P]

Modes and specs [O]

  • T2VA (text), I2VA (first frame), FL2VA (first plus last), L2VA (last frame only), Ref2VA (omni-reference: generation, video editing, video continuation, audio reuse or reference, keyframe completion).
  • 4 to 15 seconds, integers only (H3-Max 5 to 15). 24 fps. Resolution 768P or 2K (H3-Max 480P or 768P).
  • Ratios: adaptive, 21:9, 16:9, 4:3, 1:1, 3:4, 9:16. Text-to-video must specify a ratio; image-to-video is always adaptive.
  • References: up to 9 images, 3 videos (2 to 15 s each, 15 s total), 3 audio (15 s total), 12 files, request up to 64 MB. Audio cannot be sent alone.
  • Prompt up to 7,000 characters. 11 languages.
  • Trap [P]: on hosted H3, first/last frame slots and reference slots are mutually exclusive. If both are filled, one group is silently dropped and the job is still billed. To lock an opening frame and use references, put the frame in the references and call it the composition anchor.

4.1 Rules shared by all image models

  • Natural prose beats keyword stacking. Quality tags ("masterpiece", "8k", "trending") do nothing on current models. [O: BFL] [P]
  • 80 to 150 focused words beat 400 scattered ones. [P]
  • Technical lighting, not mood: "single overhead key light, soft 2:1 ratio, smooth falloff" beats "dramatic cinematic lighting". Name real materials with their finish ("board-formed concrete", "oxidized copper verdigris"). [P]
  • Palette as proportions: "60% warm ochre, 30% deep charcoal, 10% rust-red". Derive it from the brief or the references. [P]
  • In-image text: exact copy in double quotes, plus font, weight, colour and placement. Short strings are most reliable. [O]
  • Aspect ratio and resolution are parameters, never prose (Midjourney parameters excepted). [P]
  • Photoreal work: never write "character reference sheet", "model sheet", "concept art", "painterly". These pull toward illustration. Write "studio contact sheet", "photographic study sheet", "cinematic film still". [P]
  • Never name an absent thing, even to exclude it. "No ear" draws an ear. Describe the surface that occupies the place. [P]
  • Camera specs are read for look, not physics. [O: OpenAI]

5.1 3D blocking: blockout, white model, clay render

Definition. A rough untextured 3D animation (primitives or grey proxies, made in Blender, Maya, Cinema 4D, Unreal or an in-app scene builder) is given to the video model as a reference video. The model keeps the structure and regenerates the look.

  • Detail ladder, hold one rung per project: (1) capsules and primitives, (2) featureless jointed mannequin, (3) low-poly proxy with correct proportions and blank face, the default, (4) character-shaped grey model. [P]
  • Export: flat untextured shading at the delivery aspect ratio. Hide trajectory lines, axes, camera cones, grids, gizmos, selection boxes and text: anything drawn can be rendered as scene content. Keep motion blur (it is timing information). [3P] [P]
  • Coarse blockout (primitives as a motion skeleton) is reported more reliable than fine blockout (complete model re-rendered with materials). Avoid limbed stand-ins in coarse mode unless body mechanics are written per segment. [3P]
  • Iterate on the blockout, not on the prompt: re-blocking is free, re-rolls cost credits. [3P]

The channel rule [P]

Describe every channel the driver does not carry (materials, light, atmosphere, identity). Name the channels it does carry once, as a lock, and never re-describe them. Then say what the grey shapes mean (the semantic legend). Skipping the legend is why a model loses the scene after the second cut.

@Video 1 is a coarse blockout. Use its camera path, subject positions and timing.
Do not use its grey geometry, its empty grid floor or its lack of texture.
LEGEND: the grey figure standing at the rear is the woman in @Image 1; the grey box is the sedan in @Image 2; the grey walls are wet brick.
[Final look: materials, palette, light direction and quality, atmosphere, haze, depth falloff.]
[Differential secondary physics: which cloth and hair move, how much, and when.]
  • Specify the final lighting explicitly, or the flat previz light survives and the shot looks like a lit previz.
  • Add the atmosphere a grey render lacks: haze, dust, particulate, depth falloff.
  • Ask for secondary physics by name: a blockout has no cloth and no hair, so unwritten they come out frozen.
  • If motion is stiff or the camera ghosts, the text is fighting the driver: delete camera language from the prose.
  • No guaranteed phrase prevents grey leakage; the reliable mechanism is explicit mapping plus material language. [U]

@Image 1 is the exact composition, camera angle, framing, body positions and poses. Match it 100%. Do not re-frame, do not re-pose, do not move or resize anything.
@Image 2 defines [A]'s face, hair and wardrobe. @Image 3 defines the vehicle's shape, colour and materials.

5.5 Reference systems and character sheets

  • An asset is a pair: a verbatim text descriptor plus reference images. The descriptor is pasted unchanged in every prompt; the image is the anchor. State variants (wet, wounded, night) are separate assets. [P]

5.7 In-place replacement on existing footage (décor or cast) [P]

  1. Lead with a trigger verb: replace, remove, relight, restyle, change to, add. The verb switches the model into preservation mode.
  2. Name the camera move in the preservation clause. An unnamed camera move is a mutable camera move. Name motion blur and grain too.
  3. End state, never process: "replace the street with a rocky coast", not "make the street gradually become a coast".
  4. Scope every reference and exclude its backdrop and lighting.
  5. Fence with a closed positive inventory: "The world contains only the vehicle, the two figures and the rocky banks. Beyond those there is nothing." This works where a list of "no X" fails.
  • One pass, one task. At most two edit passes, décor first, then cast. A third pass visibly degrades (grade shift, waxy skin).
  • Describe posture as contact points and load, not as limb positions: "left boot planted flat on the wing, weight on both wing surfaces, knees clear of the bodywork". This also avoids false content-filter rejections.
  • Nothing is preserved bit-exact. Legible signage, logos and background crowds need rotoscoping and compositing.
  • Discard regenerated audio and re-marry the original track in the edit.

5.8 Storyboard grids and contact sheets

  • Generate a 2x2 or 3x3 grid of shots in one image: lock the subject, light direction, environment and grade; assign rows to shot types; ask for thin borders and equal spacing. [3P]

6.3 Continuity rules

  • 180-degree rule: keep the camera on one side of the axis of action so screen positions and directions stay consistent. Cross it only with a visible camera move, a shot on the line, or a re-establishing shot.
  • 30-degree rule: between consecutive shots of the same subject, move the camera at least 30 degrees or change the focal length meaningfully, or it reads as a jump cut.
  • Eyeline match: in shot and reverse shot, A looks camera-right and B looks camera-left so the gazes meet.
  • Across every cut preserve [P]: character list, geography, screen direction, gaze targets, left and right relationship, lighting direction, wardrobe, wounds, props and hand states, dirt, water, smoke, emotional progression. Do not reset action after a cut. Do not teleport characters.
  • A generative model has no memory between generations: decide once, write it down, paste it verbatim. [P]

6.4 Production pipeline and gates [P]

Breakdown, References, Style lock, Assets, Library, Generation, Edit, Cleanup, Color, Sound, Master. Nothing is generated for the film until assets and style are locked.

  • Style prefix: one paragraph of 60 to 120 words describing the render law (substrate, mark-making, line, colour model, light model, motion cadence, grain, physics register, camera grammar), pasted verbatim in every generation of the same world, versioned.
  • Defect charter: decide which artefacts are the look (grain, tape dropout, surface boil in stop-motion) and which are errors, before cleanup.
  • Shot card, four lanes: identity (who, where, when, tags), direction (goal, the character's task as a verb, what changes between first and last frame, blocking in frame-relative terms), camera (size, movement, what the camera never does, lens, angle), edit (cut type, pace, hook into the next shot).
  • Scout pass: a cheap low-resolution or short pass before any hero generation.
  • If a shot has not come together in 10 to 15 iterations, the problem is not the wording: split the shot, drop an action, change the angle.
  • One model per production block. Switching models mid-scene creates a look change grading cannot fully unify.
  • Titles and precise text are made in a graphics program, never generated.

7.4 Contact, weight, physics [P]

  • Motion has cause and effect. Walking: heel contact, weight transfer, hip shift, toe push-off. Running: real ground contact, knee lift, opposing arm swing, torso lean, varied stride.
  • Objects: the arm carries visible weight, the wrist reacts to mass, motion accelerates and decelerates.
  • Liquids cling, drip, smear, pool and follow gravity. Particles move with the wind and exist in foreground, midground and background.
  • Secondary motion: cloth delay, hair delay, follow-through.
  • A floating subject needs an anchor: a small continuous motion and a contact cue (shadow on the ground, contact patch).

7.5 Acting: behaviour under pressure [P]

Axiom: acting is behaviour, not displayed emotion. A character wants something, something is in the way, and they act to get it. Emotion is a by-product: never write it directly.

The five pillars of a scene

  1. Objective: a verb aimed at a partner ("make him confess"), never a state ("be angry").
  2. Obstacle and stakes: what prevents it and what failure costs.
  3. Tactics: action verbs (press, charm, shame, plead, provoke, bargain, stall). A living person changes tactic when one fails.
  4. Beats: each beat change must be visible: a pause, a posture change, a tempo change, a shift of gaze. Two to four beat changes per scene.
  5. Subtext: what the character wants versus what they say. It leaks through behaviour; it is not performed.

Body

  • Center of gravity: high (chest, chin: confidence, aggression) or low (shoulders, slouch: fatigue, fear).
  • Tempo: fast and ragged (nervous) or slow and economical (control, threat).
  • Breath: high and rapid (panic) or low and slow (control).
  • Business: give the hands a real task (counting money, wiping a glass). The strongest accent is the moment the business stops.
  • Proxemics: intimate under 0.5 m; personal 0.5 to 1.2 m; social 1.2 to 3.5 m; public beyond 3.5 m. A change of distance is a change of beat.
  • Status: high status is a still head, slow moves, long gazes, pauses before answering. Low status is fussing, self-touching, broken speech. Status breaks are the interesting moments.

Eye life (mandatory)

  • Micro-saccades and a gaze that keeps moving: drifts, flicks away in thought, scans a detail and settles back.
  • Blink rate tied to state: rapid bursts under stress, slow lids in control.
  • Live catchlights: eyes read wet, lit, alive.
  • Eyes lead the thought: the eyes reach the target a touch before the head turns.
  • Controlled stillness is chosen: rare, slow, deliberate blinks, and the gaze still shifts with intent.
  • The tighter the shot, the less movement: only the eyes and the thought.

Listening and ensemble

  • Reactions start before the partner's line ends. Hard answers are preceded by a micro-pause.
  • Group reactions travel in a wave, never in sync.
  • The reaction is worth more than the action: after an event, show the face that saw it.
  • The strong are still and quiet; the weak fidget and shout. Violence arrives without wind-up.
  • States have inertia: no instant recovery after a strong event.

  • Every tic has a trigger. Every mask has a crack ("However, when X...").
  • No wardrobe, no camera, no colour in the acting profile.
  • Per scene, the profile is rewritten into the moment, never pasted. A behaviour that cannot happen is transformed, not deleted (a pacer on a sofa becomes restless micro-sway).
  • Voice is locked: one voice prompt per character, pasted verbatim whenever they speak: "A [age]-year-old [origin, accent]. [Timbre and register]; [pace and delivery]; [emotional character and how it shifts under pressure]."

8.5 Lighting

  • Roles: key (brightest), fill (opens shadows), back or rim (edge separation). Practical: a lamp visible in frame. Motivated: light justified by a visible source.
  • Quality: hard light from a small source, sharp shadows; soft light from a large or diffused source.
  • High key: generous fill, few shadows. Low key: little fill, deep shadows. Chiaroscuro: extreme contrast.
  • Ratio: each stop doubles it: 1 stop is 2:1, 2 stops 4:1, 3 stops 8:1.
  • Always define [P]: primary source, direction, camera side relative to the light, which side of the subject is in shadow or rim, background brightness, exposure priority, the forbidden failure.
  • Behaviour over time: "the shadow of the blind creeps up the wall", "headlights sweep across the ceiling", "flicker from a television".
Backlit lock: Subject stays between camera and the brighter background. Camera stays on the shadow side of the subject. The entire shot is exposed for the backlight, not for the face. Only rim light, wet speculars, eye glints and environmental bounce reveal detail. No frontal key, no beauty fill.

8.7 Shutter angle and motion blur

Exposure time = (angle / 360) / frame rate. At 24 fps: 45 degrees = 1/192 s, 90 = 1/96, 180 = 1/48 (cinema norm), 270 = 1/32, 360 = 1/24. Small angles give crisp, staccato motion; large angles give smeared, fluid motion. Most engines ignore numeric shutter values: describe the result ("crisp staccato motion, almost no blur" or "heavy motion blur trailing the hands").

9. Audio and dialogue

  • Four layers: speech, ambience, effects, music. Name each one you care about, in mix order. [O: BFL]

  • Ambience once, continuous; discrete hits at their moment. Silence is an effect: "everything drops to silence for one second before the door opens". [P]
  • Music by instrumentation, tempo and behaviour: "acoustic guitar and upright bass, 80 BPM, enters under the first line, drops out when she speaks". [P]

  • Speaker attribution: by a visible trait or fixed name, every time, in multi-character scenes. One speaker per beat unless an overlap is written. [P]

12. Checklists

12.1 Video prompt, before delivery

  1. Engine, host platform and mode identified; mode legal for the assets on hand.
  2. Duration, ratio and resolution within limits and set as parameters.
  3. Subject named in the first sentence with 2 or 3 hard traits.
  4. One action and one camera move per shot or beat; each beat has an observable end state.
  5. Blocking written: positions, distances, body facing, gaze, first frame.
  6. Lens character and camera move paired with a visible consequence.
  7. Light: source, direction, camera side, exposure priority.
  8. Every reference has a role and an exclusion, in the correct token syntax for the platform.
  9. Nothing re-describes what a video reference already carries.
  10. Audio: every layer named or refused; dialogue quoted, attributed, short; subtitles refused.
  11. Exclusions expressed the way this engine expects.
  12. No banned vocabulary; no real names or brands.
  13. Shot durations sum to the total.
  14. Length within the engine's useful window.

12.2 Image prompt, before delivery

  1. Model chosen for the task (generation, edit, texture pass, typography).
  2. Ratio and resolution set as parameters.
  3. Natural prose; most important element first.
  4. Technical lighting and concrete materials.
  5. Palette derived from the brief or references.
  6. Text in quotes with typography and placement.
  7. References numbered with roles.
  8. Edits: one change, exhaustive preserve list, every removal with its fill.
  9. Positive phrasing; no absent thing named.

12.3 Blockout job

  1. Blockout carries only silhouette, scale, contact, occlusion, camera, timing.
  2. Viewport helpers hidden; delivery ratio; motion blur kept.
  3. Lock line for the carried channels, once. No camera description in the text.
  4. Semantic legend mapping each grey shape to a subject.
  5. Final light, atmosphere and secondary physics written.
  6. Start frame restyled from blockout frame 0 and approved.
  7. Recipe tested on a 3 to 4 second excerpt before the full pass.
